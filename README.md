# Barry's Big Cleanup

**A tidy world is a happy world!**

Barry is an extremely helpful purple dinosaur with an extremely questionable definition of “cleaning.” Run around cheerful neighborhoods, sanitize clutter with industrial enthusiasm, build combos, and choose increasingly irresponsible upgrades.

## Play

This is a dependency-free browser game. Open `index.html` directly, or play the GitHub Pages deployment once Pages is enabled.

### Controls

- **Move:** WASD / Arrow keys
- **Aim:** Mouse
- **Clean:** Hold left mouse button or Space
- **Mobile:** Left thumb pad to move; hold the flame button to clean in the direction Barry is moving

## v0.1 prototype

- Four escalating areas
- Destructible scenery with different toughness and score values
- Fuel / recharge system
- Combo scoring
- Random upgrade choices
- Synthesized sound and music using the Web Audio API
- Desktop and touch controls
- No external assets or dependencies
