# Barry's Big Cleanup

**A tidy world is a happy world!**

Barry is an extremely helpful purple dinosaur with an extremely questionable definition of “cleaning.” Run around cheerful neighborhoods, sanitize absolutely everything with industrial enthusiasm, build combos, and choose increasingly irresponsible upgrades.

## Play the demo

**Live demo:** https://toiletslayer.github.io/Barry-s-big-cleanup/

No install, account, build step, or download required. It runs directly in the browser.

### Controls

- **Move:** WASD / Arrow keys
- **Aim:** Mouse
- **Clean:** Hold left mouse button or Space
- **Mobile:** Left thumb pad to move; hold the flame button to clean in the direction Barry is moving

## Current prototype

The current build is a small playable arcade/incremental prototype. It is already good for a few minutes of increasingly questionable neighborhood sanitation, but the progression layer is still intentionally shallow.

Current features include:

- Four escalating cleanup areas
- Destructible scenery with different toughness and score values
- Broad flamethrower hit detection with visible hit feedback
- Fuel and automatic recharge
- Combo scoring
- Neighborhood tidiness progress
- Random upgrade choices with names such as **Friendship Fuel**, **Extra Thorough**, **Deep Clean**, **Eco Mode**, and **Long-Reach Kindness**
- Synthesized sound and music using the Web Audio API
- Desktop and touch controls
- No external assets, APIs, frameworks, or dependencies

## Where this is headed

The next big goal is making Barry's run feel like an actual progression game instead of a short score attack.

Ideas currently on the table:

- More distinct neighborhoods and increasingly absurd locations
- Permanent progression between runs
- Larger upgrade trees and upgrade synergies
- New sanitation equipment and alternate flamethrowers
- Passive / automatic cleanup tools
- More object types, hazards, environmental interactions, and chain reactions
- Area-specific objectives and challenges
- Boss encounters and people desperately trying to stop Barry from helping
- Unlockable Barry abilities and increasingly ridiculous “helpfulness” tiers
- Better visual destruction, fire effects, sound, music, and animation
- Saving progression in the browser

The guiding principle is simple:

> **If nothing remains, nothing can be dirty.**

## Project status

**Early prototype / active development.**

The gameplay loop works and the joke works. The next phase is mostly about adding enough progression, variety, escalation, and polish to keep the joke fun for much longer than a couple of minutes.
